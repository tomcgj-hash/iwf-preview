About

We map the building, then make it navigable

We are a wayfinding and spatial operations provider. We produce the indoor map, specify the positioning layer, deploy the platform and kiosks, and stay on the contract when tenants move and floor plans change.

Position

A solution provider, not an app studio

Wayfinding is usually sold as an app. The app is the smallest part of the problem. What decides whether a visitor finds the clinic, the stand or the car is whether the map is current, whether the walk graph knows which doors are open, and whether the kiosk in the lift lobby is connected to the same tenant data as the phone.

So we work from the building outward: survey, map, walk graph, positioning, then the surfaces and the integrations. We specify hardware rather than forcing one brand, including BLE, UWB and Wi-Fi based positioning, and we write the acceptance test before deployment so that accuracy is measured rather than asserted.

We do not sell consumer navigation apps, outdoor mapping, robot or drone navigation, asset tracking hardware, or surveillance. Staff location exists in our platform only for dispatch, patrol and emergency response, scoped to consenting devices during a shift.

Capability

Six things we do ourselves

Hardware is sourced to specification. Everything that determines whether the system works after handover is in-house.

Map production

Floor plate tracing, 3D modeling, POI and walk graph authoring, outdoor site modeling, map QA against the printed plan.

Positioning design

Technology selection, gateway and beacon layout, cabling schedule, floor detection method, calibration walk tests.

Platform delivery

SaaS, private cloud or on-premise installation, tenant content import, multi-venue administration, role and audit setup.

Integration

REST API, webhooks and SDK work against venue apps, parking systems, CRM, POS, signage CMS, access control and fire systems.

Kiosk and signage

Directory hardware specification, layout design, installation supervision, remote content management and spare parts.

Operations support

Tenant change handling, event map republishing, quarterly accuracy checks, platform updates and support tiers.

How we work

Scope, measure, accept

  1. 01

    Scope in writing

    Area, floors, POIs, surfaces, integrations and the accuracy target are written into the scope before any hardware is quoted.

  2. 02

    Map first

    The map and directory layer can go live before positioning calibration, which lets the venue see progress and test content early.

  3. 03

    Acceptance test

    Walk-test routes on every floor, accuracy measured per zone, kiosk and app behavior checked, then signed off line by line.

  4. 04

    Stay on

    Tenant changes, event maps, quarterly accuracy checks and platform updates are part of support, not a separate project.
